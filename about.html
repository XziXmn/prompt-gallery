这是什么

一个多渠道自动聚合的 GPT Image 2 提示词画廊。GitHub Actions 定时从各公开来源同步数据, 去重、自动分类、汉化标题后生成静态数据文件;网站纯前端渲染,托管在 GitHub Pages,零服务器。

来源条数说明

所有提示词均来自公开分享渠道,仅供学习交流,版权归原作者所有; 各来源的许可与署名详见仓库 ATTRIBUTION.md,如有侵权请提交 issue 移除。

更新机制

每 6 小时自动同步一次各源;X 热门通道每小时由上游更新。 全部数据以 JSON 形式存于仓库 data/ 目录,任何 AI 都可以通过 AI.md 中的约定直接检索,也可以用仓库自带的 MCP server 接入你自己的 AI 客户端。
